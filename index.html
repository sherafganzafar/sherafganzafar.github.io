DevSecOps CI Pipeline with Snyk Security Gate

Personal project

A reusable GitHub Actions template. Every push scans the Python dependencies with Snyk and the build fails on a high severity finding. Then the image is built and deployed to a kind cluster for a /health smoke test.

  • Snyk report summarized by a Python script that enforces the severity threshold
  • Caught a high severity gunicorn issue (HTTP Request Smuggling); fixed by upgrading to 23.0.0
  • Docker image runs as a non-root user; Kubernetes manifests include probes and resource limits

Dockerized App Deploy to Azure AKS via GitHub Actions

Personal project

A workflow that builds the image, pushes it to Azure Container Registry and deploys it to AKS, with cost controls: free tier cluster, one small node, a budget alert and an automatic cleanup workflow.

  • Pods kept restarting while the app was healthy; found probe timeouts using kubectl describe, events and logs
  • Relaxed the probes, raised resource limits and moved gunicorn to the gthread worker
  • Result: both pods ran 17 minutes with 0 restarts, then the resource group was deleted
